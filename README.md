# 📝 To-Do List

A simple and responsive **To-Do List** web application built using **HTML, CSS, and JavaScript**. It helps users organize daily tasks by adding, completing, and deleting tasks through an intuitive interface.

- ➕ Add new tasks
- ✅ Mark tasks as completed

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- A modern web browser
- Visual Studio Code (Recommended)

---

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Lavishnehra/to-do-list.git
```

### 2. Navigate to the project directory

```bash
cd to-do-list
```

### 3. Run the application

Open `index.html` directly in your browser or use the **Live Server** extension in VS Code.

---

## ▶️ Usage

- Type a task into the input field.
- Click **Add** to create a new task.
- Click a task to mark it as completed.
- Edit tasks whenever needed.
- Delete tasks you no longer need.
- Tasks are automatically saved in your browser using Local Storage.
